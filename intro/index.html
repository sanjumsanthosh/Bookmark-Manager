three steps, one file

From export to a clean list

01

Export from Chrome

Bookmarks → Bookmark manager → ⋮ → Export bookmarks. You get a standard HTML file.

02

Drop it in

The page parses it with the browser's own DOMParser. No server, no fetch, no upload.

03

Work the tree

Walk folders, review duplicates by group, and delete the ones you don't need in Chrome.

what counts as a duplicate

Three kinds of mess

KindWhat it catches
URLExact same link saved twice
DomainMany links from one site — "read later" decay
TitleSame page under slightly different names
  • Grouped view, so you decide per group instead of bookmark by bookmark.
  • Folder tree with counts, so the flat 400-item folder is obvious.
  • Badges separate a true duplicate from a same-domain cluster.
  • Nothing is deleted for you — the list is the deliverable.

honest limits

What it doesn't do

Chrome-tested only

It parses the standard Netscape bookmark format other browsers emit, but only Chrome was exercised.

Doesn't write back

No export of a cleaned file. Chrome's own manager still does the deleting.

No persistence

Reload and it's empty — there is no storage, no sync, no account.

run it yourself

One file, or a local server

# clone and open the file directly
$ git clone https://github.com/sanjumsanthosh/Bookmark-Manager
$ cd Bookmark-Manager
$ python3 -m http.server 8000

# or just open index.html in Chrome

Privacy

The bookmark file never leaves the tab. Parsing happens in-page, there is no backend, and no analytics script is loaded.
